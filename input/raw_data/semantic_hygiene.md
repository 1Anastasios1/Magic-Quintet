# Нейролингвистическая коррекция Magic Seven

| Токсичный паттерн (Удалить) | Нейро-корректная замена | Смысл трансформации (Нейро-базис) |
| :--- | :--- | :--- |
| **Являться / Есть** | Восприниматься как / Проявляться как... | Разрывает ложное тождество (Коржибски). |
| **Должен / Надо / Обязан** | Выбираю / Решаю / Намерен | Снимает стресс амигдалы, возвращает субъектность. |
| **Все / Всегда / Никто** | В данных условиях / Часто | Убирает сверхобобщение, возвращает к фактам. |
| **Это плохо / Это глупо** | Не соответствует цели / Я чувствую... | Заменяет ярлыки на наблюдения (Розенберг). |
| **Я такой человек** | Сейчас я действую так... | Поддерживает нейропластичность. |
| **Проблема** | Вызов / Ситуация / Дилемма | Активирует поисковое мышление коры. |
| **Я не могу** | Я пока не научился... | Убирает установку на беспомощность. |
| **Не / Нет / Ни** | Утвердительные формулировки | Направляет внимание на желаемый результат. |
| **Повелительное наклонение** | Предложения и просьбы | Убирает доминирование, снижает сопротивление. |
